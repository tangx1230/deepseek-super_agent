# 响应式 Todo 待办事项

用原生 HTML、CSS 和 JavaScript 实现的单页待办应用,数据保存在浏览器 `localStorage` 中,无后端、无第三方依赖。

## 运行方式

- 直接打开:双击 `todo-app/index.html`(或把文件拖入浏览器)。
- 通过静态服务器运行(推荐):

```bash
# 在仓库根目录执行
python3 -m http.server 8000
```

然后访问 <http://localhost:8000/todo-app/>。

## 文件结构

```text
todo-app/
├── index.html
├── styles.css
├── app.js
└── README.md
```

## 实现说明

- 支持新增、编辑、删除、完成切换,全部 / 未完成 / 已完成筛选,剩余数量统计和“清除已完成”。
- 新增待办时可选择一个可选的“指定时间”(日期 + 时分),保存为 ISO 时间字符串 `dueAt`;列表在标题下方显示本地时间,未指定则不显示。
- 标题上限 100 字符:采用“禁止输入”方案,输入框设置 `maxlength="100"`,并在输入区显示实时字数 `n/100` 和“最多 100 字”说明。
- 数据存储 key 为 `todo-app-items`;读取失败或数据格式非法时降级为空列表,并在 console 输出 warning。
- 旧数据兼容:没有 `dueAt` 字段的待办按“未指定时间”处理,仍可正常读取和操作。
- `localStorage` 不可用(如隐私模式)时应用仍可正常使用,只是不持久化。
- 移动优先响应式布局:桌面端为最大宽度 600px 的居中卡片,移动端占满宽度并保留 16px 内边距;按钮与可点击区域不小于 40px。
- 支持键盘操作(Tab 遍历、Enter 提交),复选框使用原生 `input[type="checkbox"]`,删除按钮带 `aria-label`。
- 无框架、无 npm 包、无内联样式与内联脚本。
