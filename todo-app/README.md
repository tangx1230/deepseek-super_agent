# 响应式待办与日程

用原生 HTML、CSS 和 JavaScript 实现的单页待办与日程应用,数据保存在浏览器 `localStorage` 中,无后端、无第三方依赖。除待办清单外,还提供月历视图,可按日期查看、添加和删除当天日程。

## 运行方式

- 直接打开:双击 `todo-app/index.html`(或把文件拖入浏览器)。
- 通过静态服务器运行(推荐):

```bash
# 在仓库根目录执行
python3 -m http.server 8000
```

然后访问 <http://localhost:8000/todo-app/>。

```text
todo-app/
```

## 实现说明

- 支持新增、编辑、删除、完成切换,全部 / 未完成 / 已完成筛选,剩余数量统计和“清除已完成”。
- 新增待办时可选择一个可选的“指定时间”(日期 + 时分),保存为 ISO 时间字符串 `dueAt`;列表在标题下方显示本地时间,未指定则不显示。
- 新增待办时可选择分类「一般 / 紧急」(默认“一般”),保存为 `priority`(`normal` / `urgent`);列表在标题前显示分类徽标,“紧急”使用红色强调;点击徽标可在「一般 / 紧急」之间切换,旧待办也能直接改分类。
- 标题上限 100 字符:采用“禁止输入”方案,输入框设置 `maxlength="100"`,并在输入区显示实时字数 `n/100` 和“最多 100 字”说明。
- 数据存储 key 为 `todo-app-items`;读取失败或数据格式非法时降级为空列表,并在 console 输出 warning。
- 旧数据兼容:没有 `dueAt` 字段的待办按“未指定时间”处理,没有 `priority` 字段的待办按“一般”处理,仍可正常读取和操作。
- 日程安排:月历以周一为一周第一天,默认显示并选中今天;今天用描边、选中日期用绿色实心标出,有日程的日期在数字下方显示圆点。支持上个月 / 下个月切换和“今天”按钮,可跨年浏览。
- 点击日历中的日期即可切换下方日程面板;面板显示所选日期、当天日程数量和日程列表(按时间升序,全天日程排在最前)。新增日程时可填写“时间 + 内容”,时间留空表示全天;支持删除单条日程。
- 日程数据独立保存在 `todo-app-schedules`(与待办互不影响),读取失败或格式非法时降级为空列表并输出 warning;日期按本地时间保存为 `YYYY-MM-DD`,避免时区偏移。
- 日历使用原生按钮并带 `aria-label` / `aria-pressed`,日程删除按钮带 `aria-label`;可点击区域不小于 40px,320px 窄屏下日历仍不横向滚动。
- `localStorage` 不可用(如隐私模式)时应用仍可正常使用,只是不持久化。
- 移动优先响应式布局:桌面端为最大宽度 600px 的居中卡片,移动端占满宽度并保留 16px 内边距;按钮与可点击区域不小于 40px。
- 支持键盘操作(Tab 遍历、Enter 提交),复选框使用原生 `input[type="checkbox"]`,删除按钮带 `aria-label`。
- 无框架、无 npm 包、无内联样式与内联脚本。

补充自测:

- 指定时间:选择 `2026-11-25 19:30` 添加 → 列表显示“时间:11月25日 19:30”,刷新后仍在;不选时间时列表不显示时间。
- 分类:默认“一般”添加 → 徽标显示“一般”;选择“紧急”添加 → 徽标显示“紧急”;刷新后分类保持,新增成功后选择重置为“一般”;点击列表徽标可在“一般 / 紧急”之间切换并持久化。
- 旧数据兼容:写入不含 `dueAt` / `priority` 的历史数据 → 正常读取并分别按“未指定时间”“一般”处理。
- 键盘操作:Tab 可从输入框遍历到添加按钮和复选框,Enter 可提交新增。
- 性能:200 条待办时,新增与切换完成状态的操作耗时均小于 100ms。
- 健壮性:`localStorage` 被禁用时应用仍可正常新增和操作,不产生未捕获异常。
- 可访问性:关键文字与背景对比度均达到 WCAG AA(≥ 4.5:1);标题输入按纯文本渲染,不执行 HTML/脚本。
